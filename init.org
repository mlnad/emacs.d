* Structure
The file is divided into several major sections:

1. Initialization: Sets up early init settings, package management, and
   environment variables.

2. Editor: Configures core Emacs behavior, including indentation, completion,
   and keybindings.

3. Completion: Implements advanced completion frameworks (e.g.,
   Vertico, Corfu) and project management tools.

4. Programming: Provides language-specific configurations for Lisp, Rust,
   Python, and more, with support for projects, LSP and debugging.

5. Writing: Enhances Org-mode and Markdown workflows, including note-taking,
   journaling, and document formatting.

6. UI: Customizes the user interface with themes, fonts, and modeline
   enhancements for a visually appealing experience.

** Tramp
TRAMP is cautious by default: every remote =file-attributes=, every
directory access and every process start is a network round trip.  The
settings below cache remote state, keep local state local, and never block
Emacs on a host that went away.  Remote backups need no configuration,
since =make-backup-files= is nil above.
#+begin_src emacs-lisp :tangle yes
(unless (eq system-type 'windows-nt)
  (setq tramp-default-method "ssh"
        ;; Connection history and auto-save files stay local, so a flaky
        ;; link never slows down startup nor blocks saving.
        tramp-persistency-file-name (moyu/cache-it "tramp")
        tramp-auto-save-directory (moyu/cache-it "tramp-autosave/")))

(with-eval-after-load 'tramp
  ;; Level 6 logs every remote command into a *tramp/...* buffer and slows
  ;; every operation down, so only be verbose when debugging.
  (setq tramp-verbose (if (getenv "DEBUG") 10 0)
        ;; Trust cached remote file attributes for a minute, instead of
        ;; re-reading them remotely (Emacs 31 defaults to 10 seconds).
        remote-file-name-inhibit-cache 60
        ;; ssh passwords stay usable for half an hour, not 16 seconds.
        password-cache-expiry (* 30 60))

  ;; Keep the $PATH of the remote login shell, so toolchains and language
  ;; servers outside /usr/bin (pyenv, ~/.local/bin, ~/.cargo/bin) are found.
  (add-to-list 'tramp-remote-path 'tramp-own-remote-path)

  ;; Copy between two remote hosts directly, not via a local temp file.
  (setq tramp-use-scp-direct-remote-copying t)

  (when (>= emacs-major-version 30)
    ;; Give up on an unresponsive host instead of hanging Dired forever.
    (setq remote-file-name-access-timeout 15))

  ;; Language servers started on the remote host talk plists.  Elements of
  ;; `tramp-remote-process-environment' are plain "NAME=VALUE" strings, a
  ;; quoted list would make TRAMP's remote environment setup signal an error.
  (add-to-list 'tramp-remote-process-environment "LSP_USE_PLISTS=true"))
#+end_src

Starting a remote process normally goes through a remote shell first.
When the host never prompts for a password (ssh keys, =ssh-agent=, shared
connections), ~tramp-direct-async-process~ skips that shell, which removes
a visible delay from remote shells, compilation and language servers.  It
is opt-in because it cannot ask for a password interactively; set
~moyu/tramp-direct-async~ in =~/.emacs.d/.cache/userconfig= to try it.
#+begin_src emacs-lisp :tangle yes
(defvar moyu/tramp-direct-async nil
  "Whether TRAMP starts remote processes without a remote shell.
This is faster, but only works when the remote host authenticates without
an interactive prompt.  Requires Emacs 30 or newer.")

(when (and moyu/tramp-direct-async (>= emacs-major-version 30))
  (connection-local-set-profile-variables
   'moyu/tramp-direct-async-profile
   '((tramp-direct-async-process . t)))
  (connection-local-set-profiles
   '(:application tramp :protocol "ssh") 'moyu/tramp-direct-async-profile))
#+end_src

(use-package savehist

** AI
LLM support is provided by [[https://github.com/karthink/gptel][gptel]].  It works in any
buffer: =gptel-send= sends the text before point (or the active region) and
inserts the response below it, =C-c g= opens the transient menu for changing the
model, system prompt, context and response destination, and =C-c G= opens a
dedicated chat buffer.

The active provider is selected by =moyu/ai-provider=, and its API key is read
from the provider's environment variable, falling back to =moyu/ai-api-key= in
=~/.emacs.d/.cache/userconfig=.  The provider name also picks the backend:
=deepseek-flash= and =deepseek-pro= use the DeepSeek backend, =claude= the Anthropic
backend and =gpt4= the OpenAI backend.  Model names are handed to the provider's
API as-is, so they need to be updated when a provider retires one.

#+name: ai-providers
| Provider       | Model           | Env               |
|----------------+-----------------+-------------------|
| deepseek-flash | deepseek-flash  | DEEPSEEK_API_KEY  |
| deepseek-pro   | deepseek-v4-pro | DEEPSEEK_API_KEY  |
| claude         | claude-sonnet-5 | ANTHROPIC_API_KEY |
| gpt4           | gpt-5.4-mini    | OPENAI_API_KEY    |

#+begin_src emacs-lisp :var providers=ai-providers :tangle yes
(defvar moyu/ai-provider-config 
  (cl-loop for row in providers
           when (string= (car row) moyu/ai-provider)
           return `(:model ,(cadr row) :env ,(caddr row)))
  "AI provider configuration.
\(:model val :env val)")

(use-package gptel
  :ensure t
  :demand t
  ;; `C-c g' opens gptel's transient menu (send, pick model/backend,
  ;; system prompt, context, response destination, ...).
  ;; `C-c G' opens a dedicated chat buffer.  `gptel-send' works in any buffer.
  :bind (("C-c g" . gptel-menu)
         ("C-c G" . gptel))
  :config
  (let* ((config moyu/ai-provider-config)
         (env (plist-get config :env))
         (model (plist-get config :model))
         ;; Prefer the provider's environment variable, fall back to the
         ;; key in `.cache/userconfig'.
         (key (lambda ()
                (or (and env (getenv env))
                    moyu/ai-api-key)))
         ;; Only the backend of the selected provider is registered; the
         ;; remaining rows of `ai-providers' are inert until selected.
         (backend (pcase moyu/ai-provider
                    ((or "deepseek" "deepseek-flash" "deepseek-pro")
                     (gptel-make-deepseek "DeepSeek" :stream t :key key))
                    ((or "claude" "anthropic")
                     (gptel-make-anthropic "Claude" :stream t :key key))
                    ((or "gpt4" "openai")
                     (gptel-make-openai "ChatGPT" :stream t :key key)))))
    (if (and backend model)
        (setq gptel-backend backend
              gptel-model model)
      (warn "moyu: no gptel backend for ai-provider %S; check `ai-providers'"
            moyu/ai-provider)))
  ;; Scroll the chat buffer as the response streams in.
  (add-hook 'gptel-post-stream-hook 'gptel-auto-scroll))

(defun moyu/define-key (keymap &rest binds)
  "Define KEY-OPs at KEYMAP."
  (while (length> binds 1)
    (define-key keymap (kbd (pop binds)) (pop binds))))

(defmacro moyu/build-map-list (&rest binds)
  `(let ((map (make-sparse-keymap)))
     (moyu/define-key map ,@binds)
     map))

(defmacro moyu/create-keymap (name doc &rest binds)
  "Define NAME as a keymap built from BINDS, documented by DOC.
BINDS is a flat list of KEY DEF pairs.  DEF is a command, a labeled
binding (LABEL . DEF) or (LABEL DEF), or a nested prefix keymap
\(LABEL SUBKEY SUBDEF ...)."
  `(defvar ,name
     (moyu/build-map-list
      ,@(cl-loop for bind in binds
                 collect (cond
                          ((not (consp bind)) bind)
                          ((eq (car bind) 'function) bind)
                          ((symbolp (cdr bind))
                           (list 'cons (car bind) (cdr bind)))
                          ((null (cddr bind))
                           (list 'cons (car bind) (car (cdr bind))))
                          (t (list 'cons (car bind)
                                   (cons 'moyu/build-map-list (cdr bind)))))))
     ,doc))

(defmacro moyu/set-leader (states keymap &rest binds)
  "Bind the KEY DEF pairs in BINDS below the leader prefix in KEYMAP.
STATES is passed on to `evil-define-key'."
  `(evil-define-key ,states ,keymap
     ,@(cl-loop for rest on binds by #'cddr
                append (list (list 'kbd (concat "<leader>" (car rest)))
                             (cadr rest)))))

#+name: face-fonts
| Face              | Family         | Size |
|-------------------+----------------+------|
| default           | JetBrains Mono |   16 |
| fixed-pitch       | JetBrains Mono |   16 |
| fixed-pitch-serif | JetBrains Mono |   16 |

#+begin_src emacs-lisp :tangle yes :var face-fonts=face-fonts
(defvar moyu/face-fonts face-fonts
  "Font configuration table.
Each row is (FACE FAMILY SIZE).  Special FACE values:
  cjk  — CJK font family for the default fontset")

(defun moyu/apply-face-fonts ()
  (when (display-graphic-p)
    (dolist (row moyu/face-fonts)
      (cl-destructuring-bind (face family size) row
        (cond
         ((string= face "cjk")
          ;; Deliberately leave :weight and :slant unspecified so Emacs can
          ;; select the corresponding LXGW WenKai variant for the active face.
          (dolist (cs '(han cjk-misc bopomofo kana))
            (set-fontset-font t cs (font-spec :family family :size size))))
         (t
          (set-face-attribute (read face) nil
                              :width 'normal :weight 'normal :slant 'normal
                              :font (font-spec :family family :size size))))))))

(add-hook 'window-setup-hook #'moyu/apply-face-fonts)
(add-hook 'after-make-frame-functions
          (lambda (frame)
            (with-selected-frame frame
              (when (display-graphic-p)
                (moyu/apply-face-fonts)))))
#+end_src
